# App bàn phím

Bàn phím Android tự viết, dùng để thử hiệu ứng ánh sáng khi bàn phím hiện lên.

## Hiệu ứng hiện có

- Quầng xanh lan toả từ giữa bàn phím ra các phím, chạy một lần rồi tắt.
- Hai dải sáng ở mép trên và dưới chạy ngược chiều nhau, mỗi dải hai lượt.

## Cách cài và thử

1. Mở thư mục này bằng Android Studio (Ladybug trở lên). Android Studio sẽ tự tạo Gradle wrapper và tải SDK cần thiết.
2. Chạy app lên máy (iQOO Z9, Android 16), hoặc Build > Build APK để lấy file cài thủ công.
3. Mở app, bấm "Mở cài đặt bàn phím" và bật bàn phím này.
4. Bấm "Chọn bàn phím" rồi chọn bàn phím này làm mặc định.
5. Mở một ô nhập chữ bất kỳ, bàn phím hiện lên là hiệu ứng chạy.

## Ghi chú

- Bản này mới là khung: phím cơ bản, chưa có bộ gõ Telex hay các thói quen gõ riêng.
- Ánh sáng là hiệu ứng trên màn hình, không điều khiển đèn LED thật của máy.
